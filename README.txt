Liraz Nutrition Planner — iPhone PWA

WHAT THIS VERSION ADDS
- iPhone-optimized touch layout
- fixed bottom navigation
- large quick-action buttons
- Today screen with remaining calories/protein/carbs/fat
- installable Home Screen web app
- offline support after first load
- all v3 features: menu, recipes, shopping, prep, tracker, custom meals, photo meals, backup/export

IMPORTANT
For full iPhone app behavior, these files need to be hosted on an HTTPS web address.
Opening index.html directly from the Files app will show the app, but iOS will not install the
service worker/offline PWA features from a local file.

EASIEST INSTALL FLOW AFTER HOSTING
1. Open the hosted app URL in Safari on iPhone.
2. Tap Share.
3. Tap "Add to Home Screen".
4. Tap Add.
5. Open the new Nutrition icon from your Home Screen.

DATA
Meal logs and custom data are saved locally in Safari on that iPhone. Use Export tracking data
periodically for backup. Data does not automatically sync to another phone/computer.

PHOTO MACRO ESTIMATES
The app stores photos and macro estimates, but does not itself analyze photos. Upload a plate
photo to ChatGPT for analysis, then enter/save the result in Photo Meals.
